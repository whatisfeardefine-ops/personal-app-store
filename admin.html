OWNER TOOLS

Store dashboard

Manage your app releases and the public catalog through your GitHub account.

1. Upload an APK

Create a GitHub Release and attach your APK file. This avoids putting large APK files directly into the website repository.

Create app release ↗

2. Publish it in the store

Edit apps.json and add your app details. Use the APK asset's download URL from its GitHub Release as downloadUrl.

Edit app catalog ↗

Example catalog entry:

{
  "apps": [
    {
      "name": "Your App",
      "version": "1.0",
      "category": "Tools",
      "minAndroid": "7.0+",
      "description": "Describe what your app does.",
      "downloadUrl": "PASTE_RELEASE_APK_URL_HERE",
      "iconUrl": ""
    }
  ]
}

3. Your repository

Only people with permission to your GitHub repository can change the catalog. This dashboard contains no password or secret token.

Open GitHub repository ↗Manage releases ↗

This is a static dashboard, not a private login system. Keep repository write access limited to yourself. Publishing a catalog change updates the public site after Pages deployment.
